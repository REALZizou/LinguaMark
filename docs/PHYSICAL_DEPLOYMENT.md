## 二、 部署形态与软硬件配置基准

系统支持**两种典型私有化落地形态**：

### 形态 A：单机极简便携式部署（最适合单年级、学科教研组试运行）
只需在教研组放置一台普通台式机或工控 Mini PC，即可带动全组 10~20 名教师日常使用：
* **宿主机硬件要求**：
  * **CPU**：Intel Core i5 8代及以上 / AMD Ryzen 5，**必须支持 AVX2 指令集**（OpenCV 向量加速计算依赖）；
  * **内存 (RAM)**：16 GB DDR4（为图片高斯平滑与透视变换预留内存缓存）；
  * **硬盘 (Storage)**：512 GB NVMe M.2 SSD（顺序读写速度 $\ge 1500\text{MB/s}$，保障百张大图秒级吞吐）；
* **操作系统**：Windows 10/11 64位（开启 WSL2）或 Ubuntu Linux 22.04 LTS。

### 形态 B：校级标准机房私有化部署（适合全校多学段、数千人统考）
部署于学校信息技术中心机房的标准机架式服务器或私有云虚拟化节点（VMware / Proxmox）：
* **服务器硬件要求**：
  * **CPU**：Intel Xeon 或 AMD EPYC，8 核心 / 16 线程及以上；
  * **内存 (RAM)**：32 GB ECC 内存；
  * **硬盘 (Storage)**：系统盘 256GB SSD + 数据盘 2TB 机械硬盘（RAID 1 或 RAID 5 镜像备份）；
* **操作系统**：Ubuntu Server 22.04 LTS / Debian 12 / Rocky Linux 9。

## 三、 客户端与线下耗材运行规格

| 节点类型 | 硬件与环境要求 | 关键技术规格与兼容标准 |
| :--- | :--- | :--- |
| **教师电脑端** | 普通工位 PC / 笔记本 | 推荐 Google Chrome $\ge 90$、Microsoft Edge $\ge 90$、Safari $\ge 15$。显示器分辨率建议 $\ge 1920 \times 1080$。 |
| **手机采集端** | 教师智能手机 (iOS / Android) | 摄像头像素 $\ge 800$ 万像素，具备自动对焦（AF）功能。运行主流移动浏览器或微信内置浏览器即可拍照直传。 |
| **纸张耗材** | 标准 A4 打印/复印纸 | **克重严格要求 $\ge 80\text{g}$ 双胶纸**。严禁使用 70g 薄纸或草稿纸，防止双面油墨透背导致客观题误判。 |
| **学生填涂耗材** | 铅笔与签字笔 | 客观题填涂必须使用 **2B 铅笔**（石墨浓度充足）；主观题书写必须使用 **0.5mm 黑色中性水笔**。 |

## 五、 Docker Compose 一键容器化部署定义

通过以下 `docker-compose.yml` 配置，在校内服务器终端执行 `docker compose up -d` 即可在 **2 分钟内一键拉起整套系统**：

```yaml
version: '3.8'

services:
  # 1. 前端与业务应用服务
  linguamark-app:
    image: linguamark/web-app:1.0.0
    container_name: linguamark_web
    restart: always
    ports:
      - "3000:3000"
    environment:
      - PORT=3000
      - NODE_ENV=production
      - DATABASE_URL=postgresql://linguamark:LinguaMarkPass2026@linguamark-db:5432/linguamark_db
      - CV_ENGINE_URL=http://linguamark-cv:5001
      - STORAGE_ROOT=/data/storage
    volumes:
      - storage_data:/data/storage
    depends_on:
      - linguamark-db
      - linguamark-cv

  # 2. 纯本地 OpenCV + ZXing 视觉处理引擎
  linguamark-cv:
    image: linguamark/cv-engine:1.0.0
    container_name: linguamark_cv
    restart: always
    environment:
      - WORKERS=4
      - OMR_CONFIDENCE_THRESHOLD=90.0
      - LAPLACIAN_BLUR_THRESHOLD=100.0
    volumes:
      - storage_data:/data/storage

  # 3. 结构化关系型数据库
  linguamark-db:
    image: postgres:14-alpine
    container_name: linguamark_postgres
    restart: always
    environment:
      - POSTGRES_USER=linguamark
      - POSTGRES_PASSWORD=LinguaMarkPass2026
      - POSTGRES_DB=linguamark_db
    volumes:
      - db_data:/var/lib/postgresql/data
    ports:
      - "127.0.0.1:5432:5432"

volumes:
  storage_data:
    driver: local
    driver_opts:
      type: none
      o: bind
      device: /opt/linguamark/data
  db_data:
```
